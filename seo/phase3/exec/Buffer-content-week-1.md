## 📝 How to publish in Buffer (5 min/day)

**One-time setup (5 min, do once):**
1. Login to https://buffer.com
2. Top right → Profile icon → "Settings"
3. "Posting Schedule" → set 5 time slots matching above
4. Save

**Daily publish (5 min):**
1. Open Buffer → "Create Post" (top right)
2. Select X channel
3. Copy paste copy from this doc
4. Drag/drop image from `assets/images/...` (paths above)
5. Pick schedule time (or "Add to Queue" if you set up schedule)
6. Click "Schedule" → done
7. Repeat 4-5 times (5 min total)

**Total: 5 min/day. Week done in 35 min.**
